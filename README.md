# Scala programming notes

Examples learned from a Derek Banas tutorial, collected in [Learning Scala Programming.scala](Learning%20Scala%20Programming.scala).
The file covers basic expressions, control flow, collections, file I/O, classes, inheritance, and traits.

## Using the notes

Treat the file as tutorial material and work through individual examples in a Scala REPL or scratch project.
It mixes commented REPL examples with a `ScalaTut` object and interactive input.
It also retains a trailing `</textarea>` HTML fragment, so the committed file is not a ready-to-compile standalone program.

The examples use Scala 2-era syntax, including older procedure and class-construction forms.
No Scala version, build definition, or automated test suite is pinned here.
Check compatibility before using a current Scala toolchain, and provide a disposable working directory for the file-writing examples.
